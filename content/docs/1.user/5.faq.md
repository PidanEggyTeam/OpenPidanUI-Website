## 杀毒软件报毒

.NET 单文件打包的组件经常被启发式引擎误判。**先看签名与来源**：文件应当来自本仓库的 Releases，哈希可与下载页核对。

确认无误后：

- Windows Defender：设置 → 病毒和威胁防护 → 排除项 → 添加皮肤目录与程序目录；
- 第三方杀软：加入信任列表，不要直接关闭实时防护。

> 如果哈希对不上，**不要继续安装**，把文件删掉并到仓库提 issue。

## 文字或图标发虚（高 DPI）

在 `HomeSettings` → 外观里把「缩放跟随系统」打开。仍然发虚的话，检查 Rainmeter 主程序是否也开启了 DPI 感知（右键快捷方式 → 属性 → 兼容性）。

## 组件加载了但不刷新

按顺序排查：

1. 托盘图标 → 刷新全部；
2. 确认皮肤的 `Update` 值没有被手改过（默认 1000）；
3. 看 Rainmeter 的日志窗口（托盘右键 → 关于 → 日志），红色行通常写着真实原因。

## 卸载后有残留吗

没有系统文件被替换，所以不需要「还原」。要清干净，删这三处：

- `Skins\OpenPidanUI`
- `%APPDATA%\OpenPidanUI`
- 若开过「开机启动」，到任务计划程序里删掉对应任务。

## 还解决不了

去 [GitHub 仓库](https://github.com/PidanUI-Team/OpenPidanUI/issues) 提 issue，附上 Rainmeter 版本、Windows 版本与日志里那几行红字。
