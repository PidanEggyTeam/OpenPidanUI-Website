## 安装 .rmskin

从[下载页](/download)拿到 `.rmskin` 文件后，直接双击。

Rainmeter 会弹出安装向导，依次确认：

1. **皮肤**：默认全选即可；
2. **布局**：如果不想覆盖现有布局，取消勾选「安装布局」；
3. **变量**：保持默认。

安装完成后，皮肤会出现在 `%USERPROFILE%\Documents\Rainmeter\Skins\` 下。

## 加载到桌面

托盘图标右键 → **管理（Manage）** → 左侧找到 `OpenPidanUI` 分组 → 选中要显示的条目 → **加载（Load）**。

如果皮肤没出现：

- 点「刷新全部（Refresh all）」；
- 确认 `.rmskin` 确实装到了上面那个目录，而不是被解压到了下载文件夹。

## 多显示器与缩放

组件的坐标是相对主显示器计算的。缩放为 125% / 150% 时如果位置偏了，在[组件设置](/docs/user/settings)里调整位置偏移，不要直接改 `.ini`。

## 卸载

管理面板里选中皮肤 → **卸载（Unload）**，再删掉 `Skins\OpenPidanUI` 目录即可。系统文件没有被改动过，不需要额外清理。
