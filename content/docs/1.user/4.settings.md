大部分外观选项都在 **HomeSettings**（组件设置程序）里，不用手改 `.ini`。

## 打开方式

两种都行：

- 开始菜单里搜 `HomeSettings`；
- 桌面上小组件右键 → **设置**。

## 能改什么

| 分组 | 项目 | 说明 |
| --- | --- | --- |
| 外观 | 主题色 | 跟随 PidanUI 主题包，改完立刻生效 |
| 外观 | 贴图 / 圆角 | 影响卡片与图标底板 |
| 声音 | 点击 / 提示音 | 可关闭 |
| 行为 | 开机启动 | 通过计划任务实现，卸载时会一并移除 |
| 位置 | 偏移与层级 | 多显示器、缩放场景下微调 |

## 配置存在哪

设置在 `%APPDATA%\OpenPidanUI\settings.json`。想备份就复制这个文件；想恢复默认删掉它，下次启动会重建。

:::caution
不要手工编辑 `settings.json` 里的字段名，版本升级时字段可能被重命名。改外观请走界面。
:::
