Rainmeter 是小组件的宿主程序。OpenPidanUI 只提供皮肤与配套设置程序，不捆绑 Rainmeter。

## 下载与安装

1. 打开 [rainmeter.net](https://www.rainmeter.net/) 的下载页，取最新正式版。
2. 安装时选 **标准安装（Standard installation）**；不确定就保持默认选项。
3. 装完首次启动，Rainmeter 会自带一套示例皮肤，说明它已经能正常工作。

:::note
便携安装（Portable installation）也能用，但皮肤与配置文件会跟着程序目录走。想换机器时整体拷贝更省事，日常使用建议标准安装。
:::

## 确认版本

右键任务栏托盘里的 Rainmeter 图标 → **关于**，看一眼版本号。OpenPidanUI 的组件按 4.5+ 的皮肤 API 编写，低于这个版本可能出现变量不生效。
