## 环境

- **.NET 10 SDK**（`dotnet --list-sdks` 能看到 `10.x`）
- **Visual Studio 2026**（或 Rider），装「.NET 桌面开发」工作负载
- **Rainmeter 4.5+**，用来加载皮肤做联调

## 命令行构建

```powershell
dotnet build Eggix-Rainmeter-Widgets/HomeSettings/HomeSettings.csproj -c Debug
```

Release 产物：

```powershell
dotnet publish Eggix-Rainmeter-Widgets/HomeSettings/HomeSettings.csproj -c Release -r win-x64 --self-contained false
```

## 调试皮肤

1. 把 `Eggix-Rainmeter-Widgets` 下的皮肤目录软链到 `%USERPROFILE%\Documents\Rainmeter\Skins\OpenPidanUI`（开发时别直接往正式目录里拷）；
2. Rainmeter 托盘 → **刷新全部**；
3. 用 [Rainmeter 日志窗口](https://docs.rainmeter.net/manual/user-interface/about/) 看变量求值结果，比打断点快。

## 调试设置程序

`HomeSettings` 是普通 WPF 应用，直接 F5。它读的配置路径可以用环境变量覆盖：

```powershell
$env:OPENPIDANUI_CONFIG = "$PWD\.devsettings\settings.json"
dotnet run --project Eggix-Rainmeter-Widgets/HomeSettings
```

## 常见编译错误

| 错误 | 原因 |
| --- | --- |
| `NETSDK1045` | SDK 版本低于 10，装新 SDK |
| `MC3074` / XAML 找不到类型 | 命名空间前缀写错，或文件没参与编译 |
| `CS0246` 找不到 `RainmeterIntegration` | 先编依赖项目，或直接从解决方案构建 |
