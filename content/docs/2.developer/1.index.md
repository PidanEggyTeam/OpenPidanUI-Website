这个仓库存放 **PidanUI 各组件的源代码**：Rainmeter 皮肤、配套的设置程序与若干独立小工具。

四篇按「看懂 → 跑起来 → 改得动 → 发得出」排列：

1. [仓库结构](/docs/developer/repo-structure)
2. [构建与调试](/docs/developer/build-and-debug)
3. [提交规范](/docs/developer/commit-style)
4. [发版流程](/docs/developer/release-flow)

技术栈：**.NET 10（`net10.0-windows`）+ C# + WPF**，皮肤本体是 Rainmeter 的 `.ini` 与脚本。
